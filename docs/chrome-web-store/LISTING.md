# Chrome Web Store listing copy

## Product name

Connection Quality for Google Flights BETA

## Short description

See whether an international flight connection is comfortable, tight, or risky before you book.

## Detailed description

THIS EXTENSION IS FOR BETA TESTING.

Connection Quality adds clear, explainable connection guidance directly to the
one-stop itinerary you are viewing on Google Flights.

Open an international one-stop itinerary to see one of four connection-quality
states: Comfortable, Reasonable, Tight, or Risky. The assessment uses the scheduled
layover and structural transfer factors that may apply, including passport control,
terminal or security steps, and explicit baggage re-check information.

Ticket protection is handled separately from the physical transfer. When Google
Flights explicitly identifies a protected connection or separate tickets, the
extension reflects that evidence. When ticket status cannot be determined reliably,
the extension asks you to confirm One protected ticket, Separate tickets, or Not
sure rather than guessing.

Current beta limitations:

- Google Flights desktop pages only.
- Designed for one expanded, one-stop itinerary at a time.
- Google Flights page changes may temporarily affect detection.
- Airport-specific transfer assumptions are available only where the project has
  defensible rules; other airports use a standard international-transfer baseline.
- Results are planning guidance, not guaranteed transfer times or travel advice.

The extension does not provide live delay prediction, missed-connection
probabilities, booking or rebooking, real-time flight tracking, weather, or
machine-learning predictions.

Connection Quality for Google Flights BETA is an independent project and is not
affiliated with or endorsed by Google.
